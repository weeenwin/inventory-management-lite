# Inventory Management Lite

A lightweight inventory dashboard built with vanilla HTML, CSS, and JavaScript.

## Run it
1. Extract the project folder.
2. Open `index.html` in a modern browser.

No package installation or build step is required. Google Fonts is optional; the site falls back to system fonts if offline.

## Features
- Dashboard metrics and stock status distribution
- Add and edit products with unique SKU validation
- Search and filter products
- Stock-in, stock-out, and quantity adjustments
- Category summaries and stock movement history
- CSV export
- Browser `localStorage` persistence on the same browser/device

## Important
This is a local, single-user prototype. Browser storage is not a database or backup, and data does not sync between devices or users. For production, add a backend, authentication, authorization, backups, and server-side validation.
